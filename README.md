## Featured Projects

### 🛒 &nbsp;Car Parts Marketplace

> Multi-vendor commerce platform built as a Turborepo monorepo — four deployable apps sharing one role-based API.

Customer storefront, vendor portal, admin dashboard and an Express API, with `CUSTOMER` / `VENDOR` / `ADMIN`
access control enforced at the route layer. Vendors manage multi-warehouse inventory and order fulfilment;
admins get analytics, bulk orders, abandoned-cart recovery and a full audit trail.

### 📄 &nbsp;AI Report Generator

> Full-stack SaaS that turns source material into structured, publication-ready reports using Claude.

A six-step wizard walks from format selection through to export, with a conversational refine-chat for
iterating on generated sections. Handles PDF and DOCX ingestion, JWT auth with OTP email verification,
and a credit system backed by Razorpay checkout.

### 🎯 &nbsp;Adaptive Interview Platform

> Resume-aware interview simulator that asks questions grounded in your actual experience.

Parses uploaded resumes to index your background, then generates questions targeted at it — escalating
difficulty as answer quality improves. A generator/critic prompt loop filters out generic questions
before they reach you, with in-browser transcription via the Web Speech API.
