## 💼 Featured Projects

### 🛒 Car Parts Marketplace — Multi-Vendor Commerce Platform
**[Source Code](https://github.com/bhuvanp124/car-parts-marketplace)**

A **Turborepo monorepo** with four independently deployable apps sharing one role-based API.

**🌟 Key Features**
- **Four-app architecture:** customer storefront, vendor portal, admin dashboard, and an Express API
- **Role-based access control:** `CUSTOMER` / `VENDOR` / `ADMIN` enforced at the route layer with JWT
- **Vendor operations:** onboarding, approvals, multi-warehouse inventory, order fulfilment
- **Admin surface:** analytics, bulk orders, abandoned-cart recovery, full audit trail
- **Infrastructure:** PostgreSQL + Redis via Docker Compose, orchestrated with pnpm workspaces

### 📄 AI Report Generator
**[Live Demo](https://ai-report-frontend-phi.vercel.app) | [Frontend](https://github.com/bhuvanp124/ai-report-frontend) | [Backend](https://github.com/bhuvanp124/ai-report-backend)**

A full-stack SaaS that turns source material into polished, structured reports using **Claude**.

**🌟 Key Features**
- **Six-step guided wizard:** format → details → info → TOC → generate → download
- **LLM engine:** Claude via the Anthropic SDK, with a conversational refine-chat for iteration
- **Document ingestion:** PDF and DOCX parsing with `pdf-parse` and `mammoth`
- **Monetisation:** credit system with Razorpay checkout and webhook handling
- **Secure auth:** JWT + bcrypt with OTP email verification via Resend
